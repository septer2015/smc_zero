# Журнал параллельного paper-режима (Э17.z++)

Этот файл сравнивает два чтения одной и той же ночи. Базовое чтение — боевой конфиг режима A
(`configs/live_eurusd_m15.yaml`), второе — исследовательский кандидат Э17.z++
(`configs/research_e17zp_candidate.yaml`: окна Лондона и Нью-Йорка сдвинуты на −3 часа, суточный
лимит настроек на уровень поднят с 1 до 3). Оба чтения запускает один и тот же скрипт
`scripts/daily_signal_check.sh`; он кладёт снимок каждого в `./tmp/paper/<роль>_<ГГГГММДД>.json`.
Карантин режима A при этом не снимается: кандидат только наблюдается, на счёт он не идёт, и
боевой конфиг не меняется.

Основание: вердикт Э17.z+ по кандидату — B, «перспективен, доказательств недостаточно»
(`tmp/e17zp_verdict.md`). Прежние окна уже прочитаны, поэтому независимые наблюдения можно
набрать только на данных, которых не видел ни один прогон, — то есть в реальном времени.

## Как вести журнал

1. В 22:00 MSK запустите проверку: `scripts/daily_signal_check.sh` (эта же строка стоит в cron).
2. Откройте два снимка дня: `./tmp/paper/base_<ГГГГММДД>.json` и
   `./tmp/paper/candidate_<ГГГГММДД>.json`. Сигналы дня — поле `signals` каждого файла.
3. Заполните строку дня: сигнал каждого чтения (сторона, уровень, цена входа) или «нет».
4. Расхождение — это разные сигналы, а не разная прибыль: сигнал, который есть в одном чтении
   и которого нет в другом. Нет ни там, ни там — пишите «нет».
5. Раз в неделю сверяйте накопленное с ожиданием движка и следите за концентрацией риска:
   кандидат допускает до трёх заходов на один уровень в сутки, поэтому позиции по одной цене
   складываются в общую нагрузку.

## Единицы и источники

| Колонка | Источник |
| --- | --- |
| дата | день запуска проверки, MSK |
| сигнал | снимок дня, поле `signals`: `open_time`, `side`, `level_name`, `entry` |
| расхождение | сигналы, которые есть только в одном из двух снимков |
| пояснение | ручная пометка: пропуск, сбой связи, всё нештатное |

Снимок дня несёт и метрики всего четырёхлетнего прогона (поле `metrics`) — это контекст, а не
результат ночи: сравнивать два чтения по ним нельзя, окна у них разные только на кандидате.
