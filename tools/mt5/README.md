# Выгрузка истории MetaTrader 5 (Э13.2)

`ExportBars.mq5` выгружает историю брокера в CSV, который читает загрузчик проекта
(`smc_zero.data_loader.load_ohlcv`, раскладка `mt5`). Свой скрипт нужен потому, что диалог
«Сохранить как» в терминале останавливается примерно на 100 000 баров. Для M5 это 1.4 года, а
walk-forward (скользящее окно обучения с проверкой на unseen-данных) просит четыре года
(`SPEC_SMC.md` §7.10 п.61).

## Шаги в терминале

1. Tools → Options → Charts → «Max bars in chart» = Unlimited.
2. Market Watch → EURUSD → открыть график M5 и прокрутить влево, чтобы терминал скачал историю.
   Надёжнее: Symbols → EURUSD → Bars → Request.
3. Скопировать `ExportBars.mq5` в `MQL5\Scripts\` терминала. В этом окружении путь такой:

   ```
   /home/com/.wine/drive_c/Program Files/MetaTrader 5 Alfa-Forex/MQL5/Scripts/
   ```

4. Открыть файл в MetaEditor и нажать Compile (F7).
5. Перетащить `ExportBars` на график EURUSD и в диалоге задать: `InpFrom = 2022.08.15 00:00`,
   `InpTo` — последняя дата, `InpChunkDays = 30`.
6. Забрать `MQL5\Files\EURUSD_M5.csv` из того же каталога терминала и положить в базу лент:

   ```
   cp '/home/com/.wine/drive_c/Program Files/MetaTrader 5 Alfa-Forex/MQL5/Files/EURUSD_M5.csv' \
      /home/com/_data/mt5/EURUSD_M5.csv
   ```

Формат вывода — раскладка MT5: `symbol,timeframe,time,open,high,low,close,tick_volume,spread,`
`real_volume`. `time` — время ОТКРЫТИЯ бара, как требует конвенция проекта (§7.10 п.62).

## Проверка ленты

```
PYTHONPATH=src python -m scripts.check_tape --symbol EURUSD --timeframe M5 --data-source mt5
```

Здоровый ответ — `вердикт    : OK`, покрытие около 0.97 и разрывы только между сессиями:

```
бары       : 300000 (дни ..., торговые ..., ожидалось ..., покрытие 0.97...)
порядок    : sorted, дубли 0, вне сетки 0, незакрытый хвост да
пропуски   : > 12 бар сетки M5 (около 1.1 ч) внутри торгового дня: 0
вердикт    : OK
```

Что искать в отчёте:

* `дубли` — стык двух выгрузок с повторённым баром;
* `вне сетки` — битый экспорт (метка не кратна периоду таймфрейма);
* низкое `покрытие` — обрезанный файл: баров меньше, чем торговых дней в окне;
* `пропуски` — дырка в истории внутри торгового дня (пауза между сессиями сюда не попадает);
* `тонкие дни` — дни, где баров заметно меньше обычного (праздники брокера).

Код выхода: `0` — OK, `1` — дефект, `2` — файл не читается.
